# SwaraTuner website

Static site for the SwaraTuner app, hosted with GitHub Pages (Jekyll).

- `privacy-policy.md` — the privacy policy, served at `/privacy-policy/`
- `index.md` — landing page

## Publishing

In the GitHub repo: **Settings → Pages → Build and deployment → Deploy from a branch**, then pick the branch and `/ (root)`.
The site will be at `https://ninad-barve04.github.io/SwaraTuner/` and the policy at
`https://ninad-barve04.github.io/SwaraTuner/privacy-policy/`.
